# AstroWorld 🌌

Website edukasi tata surya dengan desain futuristik, responsif, dan fitur interaktif.

## Fitur
- Kartu 8 planet dengan pencarian
- Dialog detail planet, fakta, diameter, suhu, jarak, dan periode orbit
- Simulasi visual orbit dengan kontrol kecepatan
- Toggle garis orbit dan tema terang/gelap
- Perbandingan diameter, suhu, dan lama revolusi
- Kuis astronomi dengan skor otomatis
- Responsif untuk desktop dan ponsel

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk mencoba website.
3. Untuk menerbitkan di GitHub, buat repository baru.
4. Upload `index.html`, `style.css`, `script.js`, dan `README.md`.
5. Buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan.

## Catatan
- Simulasi tata surya pada versi ini adalah visual CSS interaktif, bukan model astronomi 3D fisik berskala akurat.
- Google Fonts membutuhkan koneksi internet; website tetap memakai font sistem sebagai cadangan.
- Semua interaksi utama berjalan di browser tanpa backend.
